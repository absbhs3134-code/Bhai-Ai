BHAI AI — ANDROID STARTER
Target: Tecno Spark 10 Pro / Android

IMPORTANT:
- Yeh starter project hai, pehle build/test karna hoga.
- Is version mein voice input, awaaz mein jawab aur limited commands hain.
- General online AI chat abhi included nahi. Is ke liye secure backend aur AI provider key chahiye.
- API secret ko Android app ke code mein hard-code na karein.
- Voice recognition ke liye phone par speech recognition service aur internet ki zaroorat ho sakti hai.
- Torch command pehli baar camera permission maang sakti hai.

BUILD KARNE KA TAREEQA:
1. ZIP ko computer par extract karein.
2. Android Studio install/open karein.
3. File > Open se extracted BhaiAI_Android_Starter folder select karein.
4. Gradle sync complete hone dein.
5. Android SDK 35 install karne ka prompt aaye to install karein.
6. Phone mein Developer options aur USB debugging enable karein, phir USB se connect karein.
   Agar computer nahi hai, to Android Studio build ke liye kisi computer ki zaroorat hogi.
7. Run button dabayein aur phone par microphone/camera permissions allow karein.
8. App mein Speak dabayein aur commands try karein:
   - torch on
   - torch off
   - settings kholo
   - YouTube kholo
   - time kya hai

LIMITATIONS:
- Yeh app phone ko poori tarah control nahi karti.
- Calls, messages, passwords, banking ya private data ko access nahi karti.
- Android background mic, app control aur settings ke liye restrictions rakhta hai.
- Kuch Urdu speech services Roman Urdu/Urdu ko ghalat pehchan sakti hain.
